# Bank Management System

A console-based Bank Management System developed in C++.

## Overview
This project simulates basic banking operations through a menu-driven console application.

## Features
- User login
- User and permission management
- Client management: add, update, delete, and search
- Deposit and withdrawal operations
- Display client balances and total balances
- File handling for storing client and user records

## Technologies
- C++
- Standard Template Library (STL)
- File handling

## Getting Started
1. Clone or download this repository.
2. Open the source code in a C++ IDE or compiler.
3. Compile and run the program.
4. Follow the on-screen menu.

## Learning Goals
This project was built to practise C++ programming, functions, data structures, file handling, and basic access control.

## Security Note
This is an educational project, not production banking software. Use fictional test data only. Password storage and transaction validation should be reviewed before any real-world use.
